- Jalur belajar bergaya penerbangan, dengan ikon pesawat yang berpindah ke materi yang sedang dibuka
- Tiap materi dilengkapi gambar ilustrasi dan satu paragraf refleksi

- Tampilan menyesuaikan layar HP dan mode terang atau gelap

## Cara membuka

Cara paling cepat: unduh repositori ini lalu buka `index.html` di browser.

Kalau mau diakses lewat link, aktifkan GitHub Pages:

1. Buka **Settings** pada repositori, lalu pilih **Pages**.
2. Pada bagian **Build and deployment**, pilih sumber **Deploy from a branch**.
3. Pilih branch `main` dan folder `/ (root)`, lalu simpan.
4. Tunggu beberapa menit. Alamatnya akan berbentuk `https://USERNAME.github.io/NAMA-REPO/`.
